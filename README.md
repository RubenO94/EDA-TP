# Projeto EDA – Fase 1: Listas Ligadas

Implementação de um sistema de gestão de antenas e deteção de efeitos nefastos, utilizando listas ligadas em C, no âmbito da unidade curricular de Estruturas de Dados Avançadas (EDA) do curso de Engenharia de Sistemas Informáticos (IPCA).

## 📂 Estrutura do Projeto

```
├── src/                  # Código-fonte do projeto
├── include/              # Ficheiros de cabeçalho (.h)
├── docs/                 # Relatório em Markdown
├── input/                 # Ficheiros de entrada (mapas de antenas)
├── binbuild/                # Binários gerados (não incluídos)
├── Doxyfile              # Ficheiro de configuração do Doxygen
└── README.md             # Este ficheiro
```

## 🚀 Como Utilizar

1. **Compilar o projeto**:
   ```bash
   make
   ```

2. **Executar o programa**:
   ```bash
   ./bin/main
   ```

3. **Gerar documentação com Doxygen**:
   ```bash
   doxygen Doxyfile
   ```
   A documentação será gerada na pasta `docs/html`.
